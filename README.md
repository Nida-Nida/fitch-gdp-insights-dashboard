# fitch-gdp-insights-dashboard
This Power BI project presents a dynamic and interactive dashboard that analyzes countries based on their Fitch credit ratings, economic outlooks, GDP per capita, and WTO membership status. The goal is to explore global economic and creditworthiness patterns and how they relate to national wealth.
# Nations Ranked by Fitch Ratings and GDP Per Capita Insights
This Power BI project presents an interactive dashboard analyzing nations based on their **Fitch credit ratings**, **economic outlooks**, **GDP per capita**, and **WTO membership**. It helps visualize the economic and political standing of countries and draws insights on how creditworthiness relates to national wealth.
## Dashboard Features
- **Bar Chart**: Average GDP per capita by Fitch Rating
- **Stacked Column Chart**: GDP trends across Fitch Outlooks and Ratings
- **Treemap**: Per capita GDP comparison by nation
- **Pie Chart**: Distribution of WTO member vs non-member countries
- **Map Visual**: Geographic representation of economic strength
- **Interactive Slicers**: Filter by Rating, Outlook, or WTO Status
## Dataset Fields
- `Nation`
- `Fitch Rating` (e.g., AAA, BBB, BB-)
- `Fitch Outlook` (e.g., Stable, Positive, Negative)
- `Per Capita GDP ($)`
- `WTO Status` (Member / Non-member)
## Tools & Technologies
- [Power BI Desktop](https://powerbi.microsoft.com/)
- DAX (Data Analysis Expressions)
- Custom themes and color palette (yellow, orange-based visuals on dark background)
## Objective
The goal of this dashboard is to:
- Evaluate how global credit ratings correlate with GDP per capita
- Identify regional economic strengths and weaknesses
- Explore the impact of WTO membership in relation to national economic performance
## How to Use
1. Clone or download the repository
2. Open the `.pbix` file in **Power BI Desktop**
3. Explore interactive visuals and filters
4. Optionally, replace the sample data with your own dataset
